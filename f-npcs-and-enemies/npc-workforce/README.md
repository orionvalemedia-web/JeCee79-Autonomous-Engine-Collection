# NPC Workforce System

> A staffing engine for any game: your buildings define the jobs and the engine supplies the workers.

**100% Zero-Dependency, True Drop-In-And-Play Setup. No Requires, No External API Packets.**

**Price:** Coming soon

## How it runs itself

1. The engine finds workplaces and works out how many people each one needs.
2. It creates workers, houses them, sends them to work and gives them breaks and shifts.
3. Buildings added during Play join on their own, and lost workers are replaced.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Mark buildings, homes and vehicles with attributes; no names or lists are needed.
- One hook tells your code when work starts, happens, pauses and ends.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
