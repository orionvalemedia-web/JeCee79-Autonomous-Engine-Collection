## How it runs itself

1. Sites produce and need goods.
2. Haulers carry cargo from where it is made to where it is needed.
3. Stock levels change as deliveries arrive, and the haulers respond.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Read stock levels at any site from your own scripts.
- Add your own sites and goods as data.
