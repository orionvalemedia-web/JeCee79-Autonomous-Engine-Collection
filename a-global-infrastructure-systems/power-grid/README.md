## How it runs itself

1. Power starts at the plant and flows out through substations to the town poles.
2. Every light and building on the grid checks whether power is reaching it.
3. Cut a line and everything past the break goes dark until it is repaired.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Read the power state of any building from your own scripts.
- Hook repair jobs or rewards to the moment a line is fixed.
