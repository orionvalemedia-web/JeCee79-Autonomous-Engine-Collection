# Meridian Airport

> An airport that runs on a timetable: planes land and leave one at a time while crew and passengers work around them.

**100% Zero-Dependency, True Drop-In-And-Play Setup. No Requires, No External API Packets.**

## How it runs itself

1. Flights follow a timetable shown on the departures board.
2. Only one aircraft uses the runway at a time; the others hold and land in order.
3. A telescoping bridge meets the aircraft and the ground crew service it.
4. Passengers walk through the terminal, and players can buy tickets.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Drop-in settings inside the model.
- An entrance road that links itself to a nearby road.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
