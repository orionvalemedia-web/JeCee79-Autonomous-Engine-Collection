> A complete underground metro: stations, gates and trains that arrive and depart on their own.

## How it runs itself

1. Trains run on a loop from station to station with no driver needed.
2. Each station has working gates and platforms.
3. Players can ride, get off and catch the next train.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Settings for train timing and dwell time at each station.
- Put your own terrain on top; the tunnels stay below it.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
