## How it runs itself

1. The road network is stored as data inside the model, so cars know every lane and junction the moment the server starts.
2. One server script spawns the cars, picks each car's next road and handles who goes first at a crossroads.
3. Cars are moved on the server, so every player sees the same traffic.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Settings values inside the model for car count, speed and spawn rate.
- Add your own roads to the network data and the cars use them.
