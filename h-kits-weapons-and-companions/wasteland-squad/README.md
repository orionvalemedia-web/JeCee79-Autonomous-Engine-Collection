# Autonomous Wasteland Squad

> A crew of wasteland survivors that fights beside the player: 20 classes, from Scavenger to Warlord.

## How it runs itself

1. Scavengers, bruisers, sharpshooters, dog wranglers, gyro pilots and more follow the player and fight on their own.
2. They level up to 100 and their rust-and-scrap gear changes as they grow.
3. Kills pay the player.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Squad size setting, up to 12 survivors.
- Built to drop into The Fallen Frontier or any wasteland game.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
