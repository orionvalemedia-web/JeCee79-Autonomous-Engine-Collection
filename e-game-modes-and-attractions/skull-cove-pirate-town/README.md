# Skull Cove Pirate Town

> A large walled pirate town on the coast with docks, a fishing port, a lighthouse and a dungeon.

## How it runs itself

1. The town sits behind a palisade on the land side, open to the docks on the sea side.
2. Pirate ships are moored at the docks and the fishing harbour sits at sea level.
3. Players can enter the cave dungeon by the shore and fight pirates.

Everything runs on the server, so every player sees the same thing at the same time.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

any script and see exactly what it does.
