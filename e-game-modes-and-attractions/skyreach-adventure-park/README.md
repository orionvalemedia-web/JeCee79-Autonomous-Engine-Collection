# Skyreach Adventure Park

> A huge modern theme park with rides, a railway, Wildgrove Zoo and guests who live by their needs.

**100% Zero-Dependency, True Drop-In-And-Play Setup. No Requires, No External API Packets.**

**Price:** Coming soon  
**Category:** Game Modes and Attractions  
**Store:** [JeCee79 on the Roblox Creator Store](https://create.roblox.com/store/creator/2604844872)

## How it runs itself

1. Guests arrive in stages, buy tickets and queue for rides.
2. They eat, drink, sit down to rest and visit the zoo as their needs change, then leave when their energy runs out.
3. Rides include a roller coaster, log flume, carousel, go-karts and bumper cars, with a park train around the edge.
4. Players can ride the rides and drive the go-karts and bumper cars.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Staff and guests are NPC Cast figures.
- The model can be moved and turned, because everything is measured from markers inside it.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
