> A whole medieval kingdom in one model: a walled capital, villages, people with daily lives, an economy and a daily joust.

## How it runs itself

1. About 150 townsfolk follow a daily schedule: work, market, meals and home.
2. Wagons carry goods between the capital and the villages, and market boards show what is for sale.
3. Thieves steal, guards catch them, and they go to the gaol and then to court.
4. Every day knights joust at the tourney ground outside the West Gate.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Built from plain parts only, so everything is visible the moment it is dragged in.
- Hook your own rewards to trade, crime and the joust.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
