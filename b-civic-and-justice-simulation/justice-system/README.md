# Justice System (Standalone)

> The legal, court and jail core of the Justice District on its own, to drop into any city.

**100% Zero-Dependency, True Drop-In-And-Play Setup. No Requires, No External API Packets.**

**Price:** Coming soon  
**Category:** Civic and Justice Simulation  
**Store:** [JeCee79 on the Roblox Creator Store](https://create.roblox.com/store/creator/2604844872)

## How it runs itself

1. The same call, arrest, jail and court pipeline as the full district.
2. Lighter: no city attached, so it fits into the world you already have.

Everything runs on the server, so every player sees the same thing at the same time.

## Hooks for developers

- Attach it to your own buildings and they become part of the system.

## Setup

1. Insert the model from the Creator Store.
2. Drag it into Workspace.
3. Press Play.

There is nothing else to set up.

## Clean, readable code

Every script is plain, readable Luau. Nothing is hidden or scrambled, and nothing is loaded
from outside the model: no `require` of an asset id, no paid keys, no web calls. You can open
any script and see exactly what it does.
